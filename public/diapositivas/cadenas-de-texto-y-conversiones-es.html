Cadenas de texto y conversiones

JAVA / FUNDAMENTOS

Trabajar con texto

Una cadena es inmutable: una transformación produce un texto nuevo.

Una cadena guarda texto, aunque ese texto contenga cifras. Antes de calcular, decide si necesitas tratarlo como texto o como número.

Para conservar una transformación, guarda el resultado. Concatena con + y compara el contenido con equals.

Ejemplo Java
String texto = "hola";
texto = texto.toUpperCase();
System.out.println(texto); // HOLA

JAVA / FUNDAMENTOS

Concatenar

Si un operando es texto, + une el texto.

Cuando un operando es String, + concatena. Los paréntesis permiten calcular primero una suma y unir después su resultado al texto.

"12" es texto; se concatena con 3 y se obtiene "123".

Ejemplo Java
System.out.println("12" + 3);

JAVA / FUNDAMENTOS

Comparar el contenido

equals compara el texto de dos cadenas.

equals comprueba el contenido y distingue mayúsculas de minúsculas. == comprueba si las referencias apuntan al mismo objeto.

¿Qué se muestra?

Ver la explicación

Las dos cadenas contienen exactamente Alex. equals distingue mayúsculas y minúsculas.

Ejemplo Java
String nombre = "Alex";
System.out.println(nombre.equals("Alex"));

JAVA / FUNDAMENTOS

Convertir antes de calcular

parseInt convierte un texto con formato entero en un int.

La conversión produce un int que puede utilizarse en cálculos. La variable de texto original sigue conteniendo una cadena.

¿Qué se muestra?

Ver la explicación

Ahora numero es un int; + realiza una suma numérica.

Ejemplo Java
int numero = Integer.parseInt("12");
System.out.println(numero + 3);

JAVA / FUNDAMENTOS

Detectar un formato incorrecto

El texto debe tener el formato del número que queremos obtener.

parseInt exige un texto con formato entero y un valor dentro del rango de int. Un formato incorrecto provoca NumberFormatException.

¿Qué ocurre?

Ver la explicación

3.5 no es un texto con formato entero. Double.parseDouble("3.5") permite obtener el decimal.

Ejemplo Java
int numero = Integer.parseInt("3.5");

PRUEBA Y OBSERVA

¿Texto o número?

Compara concatenar con sumar después de convertir. parseInt necesita un entero entre −2147483648 y 2147483647, sin espacios.

Observa que el mismo dato puede producir resultados distintos: concatenar conserva el texto; convertir permite realizar una suma numérica.
