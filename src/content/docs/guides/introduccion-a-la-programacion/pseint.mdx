En **Algoritmos y programas** hemos aprendido a describir una solución mediante datos, operaciones, instrucciones y estructuras de control. Ahora aplicaremos esos conceptos en **[PSeInt](https://pseint.sourceforge.net/)**: partiremos de lo que ya conocemos, veremos cómo se escribe en la herramienta y lo probaremos con ejemplos.

| Lo que ya conocemos | Cómo lo aplicaremos en PSeInt |
| --- | --- |
| Un algoritmo tiene un inicio, unos pasos y un final. | Escribimos los pasos entre `Algoritmo` y `FinAlgoritmo`. |
| Las variables guardan datos de un tipo determinado. | Las declaramos con `Definir nombre Como Tipo;`. |
| La entrada proporciona datos al algoritmo. | Recogemos los datos del teclado con `Leer`. |
| La asignación guarda el resultado de una expresión. | Escribimos `<-` para guardar un valor en una variable. |
| La salida comunica el resultado. | Usamos `Escribir` para mostrarlo en pantalla. |
| Los condicionales eligen qué instrucciones ejecutar. | Utilizamos `Si`, `Sino` y `Segun`. |
| Los bucles repiten instrucciones. | Utilizamos `Mientras`, `Repetir` y `Para`. |

## Del algoritmo al pseudocódigo

En el apartado **Representación de un algoritmo** vimos que el pseudocódigo permite expresar una solución con instrucciones cercanas al lenguaje natural. Para ejecutarlo en PSeInt, concretamos esa escritura: el `Inicio` y el `Fin` de nuestros ejemplos pasan a ser `Algoritmo NombreDelPrograma` y `FinAlgoritmo`.

**Ejemplo: calcular el área de un triángulo.** En papel, los pasos son: conocer la base y la altura, multiplicarlas y dividir el producto entre dos. Suponemos que las medidas son positivas y están expresadas en la misma unidad.

```text
Algoritmo AreaTriangulo
    Definir base, altura, area Como Real;
    //Mostramos un mensaje al usuario
    Escribir "Introduce la base:";
    //Recogemos el valor introducido y lo guardamos en la variable base
    Leer base;
    //Mostramos otro mensaje al usuario
    Escribir "Introduce la altura:";
    //Recogemos el valor introducido y lo guardamos en la variable altura
    Leer altura;

    //Con los datos proporcionados por el usuario, realizamos el cálculo y lo asignamos a la variable area
    area <- (base * altura) / 2;
    //Mostramos el resultado al usuario
    Escribir "El area del triangulo es: ", area;
FinAlgoritmo
```

Con base `5` y altura `8`, el resultado es `20` unidades cuadradas.

| Parte del programa | Ejemplo | Para qué sirve |
| --- | --- | --- |
| Inicio y nombre | `Algoritmo AreaTriangulo` | Identifica el algoritmo. |
| Declaraciones | `Definir base, altura, area Como Real;` | Indica las variables y sus tipos. |
| Instrucciones | `Leer base;`, el cálculo y `Escribir` | Realiza los pasos del algoritmo. |
| Final | `FinAlgoritmo` | Delimita el final del programa. |

La sangría ayuda a reconocer qué instrucciones pertenecen a cada bloque. Los comentarios empiezan por `//` y sirven para explicar el código.

### Palabras reservadas de PSeInt

Las **palabras reservadas** tienen un significado especial en PSeInt y forman parte de su forma de escribir los algoritmos. Por ejemplo, `Algoritmo` y `FinAlgoritmo` delimitan uno; `Definir` y `Como` declaran variables; `Si` y `Entonces` introducen una condición; y `Mientras` inicia una repetición. No podemos usar estas palabras como nombres de variables.

<aside class="java-document-note">
<p><strong>UNA RECETA QUE SE PUEDE EJECUTAR</strong></p>
<p>Un algoritmo se parece a una receta: indica qué necesitamos y qué pasos seguimos. PSeInt es el ayudante que sigue las instrucciones escritas. Para calcular el área, la base y la altura son los ingredientes; multiplicar y dividir son los pasos; el área es el plato terminado. Si cambias las medidas, utilizas la misma receta con otros datos.</p>
</aside>

## Datos, variables y constantes

### Tipos de datos y declaraciones

En **Datos** distinguimos enteros, reales, valores lógicos, caracteres y cadenas. En PSeInt indicamos el tipo al declarar cada variable con `Definir`. El tipo `Caracter` permite guardar tanto una letra como un texto completo: esta es una diferencia respecto a la distinción conceptual entre carácter y cadena que ya conocemos.

| Tipo en PSeInt | Valores de ejemplo | Uso |
| --- | --- | --- |
| `Entero` | `0`, `12`, `-3` | Cantidades sin decimales. |
| `Real` | `8.5`, `0.98` | Medidas y cantidades con decimales. |
| `Caracter` | `"A"`, `"Ana"` | Un carácter o una cadena de texto. |
| `Logico` | `Verdadero`, `Falso` | Indicar si se cumple una condición. |

```text
Algoritmo FichaJugador
    Definir monedas Como Entero;
    Definir tiempo Como Real;
    Definir nombre Como Caracter;
    Definir tieneLlave Como Logico;

    monedas <- 12;
    tiempo <- 8.5;
    nombre <- "PixelNinja";
    tieneLlave <- Verdadero;

    Escribir "Jugador: ", nombre;
    Escribir "Monedas: ", monedas;
    Escribir "Tiempo: ", tiempo;
    Escribir "Tiene llave: ", tieneLlave;
FinAlgoritmo
```

El programa muestra los cuatro valores asignados. Los decimales se escriben con punto y los textos entre comillas dobles.

<aside class="java-document-note">
<p><strong>EL INVENTARIO DE UN VIDEOJUEGO</strong></p>
<p>Piensa en la ficha de tu personaje: las monedas se cuentan con un <code>Entero</code>, el tiempo de carrera se mide con un <code>Real</code>, el nombre se guarda como <code>Caracter</code> y tener llave se representa con un <code>Logico</code>. Antes de declarar una variable, pregúntate: <strong>¿qué necesito guardar en esta casilla?</strong></p>
</aside>

### Variables y valores que mantenemos fijos

En **Variables y constantes** comparamos una variable con una caja etiquetada que guarda información en la memoria. En PSeInt, `Definir` declara esa variable y `<-` permite guardar o sustituir su contenido. También vimos que una constante representa un valor que debe mantenerse fijo. En estos ejemplos, los valores fijos se guardan en variables con nombre en mayúsculas y **no se vuelven a asignar**: esta convención expresa nuestra intención, pero no impide que PSeInt permita modificarlos.

```text
Algoritmo PremioDelCofre
    Definir monedas, PREMIO Como Entero;

    PREMIO <- 5;
    monedas <- 10;
    monedas <- monedas + PREMIO;

    Escribir "Monedas: ", monedas;
    Escribir "Premio de cada cofre: ", PREMIO;
FinAlgoritmo
```

El resultado es `15` monedas y un premio de `5`. La asignación lee el valor anterior de `monedas`, suma el premio y guarda el resultado en la misma variable.

<aside class="java-document-note">
<p><strong>LA CAJA CONSERVA SU ETIQUETA</strong></p>
<p>En nuestra estantería de la memoria, la caja <code>monedas</code> contiene <code>10</code>. Al ejecutar <code>monedas &lt;- monedas + 5;</code>, consultamos lo que hay dentro, calculamos <code>15</code> y sustituimos el contenido. La etiqueta sigue siendo <code>monedas</code>. La caja guarda el valor nuevo; no conserva automáticamente una colección de sus valores anteriores.</p>
</aside>

## Expresiones y operadores

En **Operadores** utilizamos expresiones para calcular valores, compararlos y combinar condiciones. En PSeInt hacemos las mismas operaciones; lo que debemos concretar es la escritura de algunos símbolos. Por ejemplo, `(base * altura) / 2` produce un número y `edad >= 18` produce un valor lógico.

### Expresiones aritméticas

| Operación | Escritura en PSeInt | Resultado del ejemplo |
| --- | --- | --- |
| Suma | `7 + 2` | `9` |
| Resta | `7 - 2` | `5` |
| Multiplicación | `7 * 2` | `14` |
| División | `7 / 2` | `3.5` |
| Resto de una división entera | `7 MOD 2` | `1` |
| Potencia | `2 ^ 3` | `8` |

```text
Algoritmo RepartirMonedas
    Definir monedas, personas, enteras, sobrantes Como Entero;
    Definir reparto Como Real;

    monedas <- 17;
    personas <- 5;
    reparto <- monedas / personas;
    enteras <- TRUNC(reparto);
    sobrantes <- monedas MOD personas;

    Escribir "Division: ", reparto;
    Escribir "Monedas enteras por persona: ", enteras;
    Escribir "Sobran: ", sobrantes;
FinAlgoritmo
```

Los resultados son `3.4`, `3` y `2`. `TRUNC` elimina la parte decimal. El divisor debe ser distinto de cero. Los paréntesis permiten cambiar el orden: `2 + 3 * 4` vale `14`, mientras que `(2 + 3) * 4` vale `20`.

En el apartado **Operadores** aparecieron abreviaturas como `+=` y `++`. Para expresar esas actualizaciones en nuestros ejemplos de PSeInt, escribiremos el cálculo y la asignación completos:

| Notación abreviada | Forma que usaremos en PSeInt |
| --- | --- |
| `x += 3` | `x <- x + 3;` |
| `x -= 3` | `x <- x - 3;` |
| `x /= 2` | `x <- x / 2;` |
| `x %= 2` | `x <- x MOD 2;` |
| `x++` | `x <- x + 1;` |
| `x--` | `x <- x - 1;` |

### Expresiones relacionales

Comparan valores y producen `Verdadero` o `Falso`.

| Comparación | Operador | Ejemplo verdadero |
| --- | --- | --- |
| Mayor que | `>` | `8 > 5` |
| Menor que | `<` | `5 < 8` |
| Mayor o igual que | `>=` | `8 >= 8` |
| Menor o igual que | `<=` | `5 <= 8` |
| Igual que | `=` | `8 = 8` |
| Distinto de | `<>` | `8 <> 5` |

```text
Algoritmo CompararEdad
    Definir edad Como Entero;
    Definir mayorDeEdad Como Logico;

    Escribir "Introduce tu edad:";
    Leer edad;
    mayorDeEdad <- edad >= 18;
    Escribir "Es mayor de edad: ", mayorDeEdad;
FinAlgoritmo
```

Con `18`, la comparación es verdadera; con `17`, es falsa.

<aside class="java-document-note">
<p><strong>COMPARAR Y ASIGNAR SON ACCIONES DIFERENTES</strong></p>
<p>Usamos <code>=</code> para comparar y <code>&lt;-</code> para guardar un valor. <code>edad = 18</code> pregunta si la edad vale 18; <code>edad &lt;- 18;</code> cambia su valor. Las comparaciones <code>==</code> y <code>!=</code> que vimos en <strong>Operadores</strong> se escriben aquí como <code>=</code> y <code>&lt;&gt;</code>.</p>
</aside>

### Expresiones lógicas

`Y` exige que ambas condiciones sean verdaderas; `O`, que al menos una lo sea; `NO` invierte un valor lógico. Usaremos estas palabras en lugar de `&&`, `||` y `!`.

| A | B | A Y B | A O B |
| --- | --- | --- | --- |
| Verdadero | Verdadero | Verdadero | Verdadero |
| Verdadero | Falso | Falso | Verdadero |
| Falso | Verdadero | Falso | Verdadero |
| Falso | Falso | Falso | Falso |

`NO Verdadero` es `Falso` y `NO Falso` es `Verdadero`.

```text
Algoritmo ComprobarNumero
    Definir numero Como Entero;
    Definir impar, alMenosDiez, enIntervalo Como Logico;

    Escribir "Introduce un numero entero:";
    Leer numero;
    impar <- (numero MOD 2) <> 0;
    alMenosDiez <- (numero > 10) O (numero = 10);
    enIntervalo <- (numero >= 10) Y (numero <= 20);

    Escribir "Es impar: ", impar;
    Escribir "Es al menos 10: ", alMenosDiez;
    Escribir "Esta entre 10 y 20: ", enIntervalo;
    Escribir "Esta fuera del intervalo: ", NO enIntervalo;
FinAlgoritmo
```

Con `15`, los tres primeros resultados son verdaderos y el último es falso. Prueba también `9`, `10`, `20` y `21` para comprobar los límites del intervalo.

<aside class="java-document-note">
<p><strong>LAS REGLAS DE ACCESO A UNA MISIÓN</strong></p>
<ul>
<li><strong>Y:</strong> necesitas una llave <strong>y</strong> diez monedas; deben cumplirse los dos requisitos.</li>
<li><strong>O:</strong> puedes entrar con una llave <strong>o</strong> un pase; también puedes entrar si tienes ambos.</li>
<li><strong>NO:</strong> si <code>puertaAbierta</code> es verdadero, <code>NO puertaAbierta</code> es falso.</li>
</ul>
<p>Recuerda: <strong>Y pide todo; O acepta al menos una opción; NO invierte la respuesta.</strong></p>
</aside>

## Entrada, salida y asignación

En **Partes de un algoritmo** distinguimos entrada, proceso y salida; en **Instrucciones** las expresamos con `LEER`, asignaciones e `IMPRIMIR`. En PSeInt recogemos los datos con `Leer`, guardamos los cálculos con `<-` y mostramos los resultados con `Escribir`. Las instrucciones se ejecutan una detrás de otra.

| Instrucción | Acción | Ejemplo |
| --- | --- | --- |
| `Leer` | Recoge un dato del teclado y lo guarda en una variable. | `Leer euros;` |
| `Escribir` | Muestra un mensaje, un valor o varios elementos. | `Escribir "Euros: ", euros;` |
| `<-` | Calcula una expresión y guarda su resultado. | `dolares <- euros / EUROS_POR_DOLAR;` |

**Ejemplo: convertir euros a dólares.** Usaremos el supuesto del ejercicio: **1 dólar equivale a 0,98 euros**. Es un dato fijo para practicar, no una cotización actual.

```text
Algoritmo ConvertirMoneda
    Definir euros, dolares, EUROS_POR_DOLAR Como Real;

    EUROS_POR_DOLAR <- 0.98;
    Escribir "Introduce la cantidad en euros:";
    Leer euros;
    dolares <- euros / EUROS_POR_DOLAR;
    Escribir "La cantidad en dolares es: ", dolares;
FinAlgoritmo
```

Con `98` euros se obtienen `100` dólares. Dividimos porque cada dólar cuesta `0.98` euros. `Leer` guarda la entrada en la variable `euros`; no se utiliza para modificar el valor fijo del cambio.

<aside class="java-document-note">
<p><strong>UNA CALCULADORA CON PANTALLA</strong></p>
<p>Cuando tecleas una cantidad, das una <strong>entrada</strong>; cuando la calculadora opera, realiza el <strong>proceso</strong>; cuando ves el resultado, recibes la <strong>salida</strong>. En nuestro conversor, <code>Leer euros;</code> recoge el dato, el cálculo obtiene los dólares y <code>Escribir</code> los muestra. Mostrar «Introduce los euros» no recoge la respuesta: después hace falta <code>Leer</code>.</p>
</aside>

## Condicionales

Una condición permite elegir qué instrucciones ejecutar. En PSeInt escribimos cada bloque con sus palabras de apertura y cierre.

| Estructura que ya conocemos | Escritura en PSeInt |
| --- | --- |
| `IF`: actuar si se cumple una condición. | `Si condicion Entonces ... FinSi` |
| `IF-ELSE`: elegir entre dos alternativas. | `Si condicion Entonces ... Sino ... FinSi` |
| Condiciones encadenadas. | Un nuevo bloque `Si` dentro del `Sino`. |
| `SWITCH`: elegir según el valor de una opción. | `Segun opcion Hacer ... FinSegun` |

### Condicional simple: Si

**Ejercicio:** mostrar `Hola` únicamente si el número introducido es mayor que 3.

```text
Algoritmo SaludoCondicional
    Definir numero Como Real;

    Escribir "Introduce un numero:";
    Leer numero;
    Si numero > 3 Entonces
        Escribir "Hola";
    FinSi
FinAlgoritmo
```

Con `4` muestra `Hola`; con `3` no muestra el saludo. Al terminar el `Si`, la ejecución continúa después de `FinSi`.

### Condicional doble: Si y Sino

**Ejercicio:** indicar si un entero es par o impar.

```text
Algoritmo ParOImpar
    Definir numero Como Entero;

    Escribir "Introduce un numero entero:";
    Leer numero;
    Si numero MOD 2 = 0 Entonces
        Escribir "El numero introducido es par.";
    Sino
        Escribir "El numero introducido es impar.";
    FinSi
FinAlgoritmo
```

Con `8` elige la primera rama y con `7`, la segunda. El `0` también es par.

### Condicional múltiple: condiciones encadenadas

Cuando hay varias alternativas, podemos colocar otro `Si` dentro de un `Sino`.

**Ejemplo:** clasificar una nota. Primero descartamos valores fuera de 0 a 10; después distinguimos suspenso, aprobado y notable o sobresaliente.

```text
Algoritmo ClasificarNota
    Definir nota Como Real;

    Escribir "Introduce una nota de 0 a 10:";
    Leer nota;
    Si (nota < 0) O (nota > 10) Entonces
        Escribir "Nota no valida.";
    Sino
        Si nota < 5 Entonces
            Escribir "Suspenso.";
        Sino
            Si nota < 7 Entonces
                Escribir "Aprobado.";
            Sino
                Escribir "Notable o sobresaliente.";
            FinSi
        FinSi
    FinSi
FinAlgoritmo
```

Con `4` muestra `Suspenso`; con `6`, `Aprobado`; con `9`, `Notable o sobresaliente`; con `11`, `Nota no valida`. Cada `Si` tiene su propio `FinSi`.

<aside class="java-document-note">
<p><strong>UNA COLA DE PREGUNTAS</strong></p>
<p>Las condiciones encadenadas funcionan como una persona que te hace preguntas por orden y se detiene al encontrar la respuesta que decide tu caso. En las notas: «¿Está fuera de rango?», «¿Es menor que 5?», «¿Es menor que 7?». Una nota de <code>4</code> también es menor que <code>7</code>, pero ya ha entrado en la rama de suspenso. <strong>El orden de las preguntas importa.</strong></p>
</aside>

Usa condiciones encadenadas y comprueba los límites <code>-1</code>, <code>0</code>, <code>50</code> y <code>80</code>.</p>

### Selección entre opciones: Segun

`Segun` permite elegir entre varios casos. Resulta útil cuando una opción numérica determina la acción.

```text
Algoritmo MenuTresOpciones
    Definir opcion Como Entero;

    Escribir "Selecciona una opcion:";
    Escribir "1. Opcion 1";
    Escribir "2. Opcion 2";
    Escribir "3. Opcion 3";
    Leer opcion;

    Segun opcion Hacer
        1:
            Escribir "Has seleccionado la opcion 1.";
        2:
            Escribir "Has seleccionado la opcion 2.";
        3:
            Escribir "Has seleccionado la opcion 3.";
        De Otro Modo:
            Escribir "La opcion seleccionada no es valida.";
    FinSegun
FinAlgoritmo
```

Con `2` muestra la opción 2; con `8`, el mensaje de opción no válida. Solo se ejecuta el caso seleccionado: no hay que añadir un `break`.

<aside class="java-document-note">
<p><strong>LOS BOTONES DE UN ASCENSOR</strong></p>
<p><code>Segun</code> se parece a elegir una planta: pulsas un número y se realiza la acción asociada a ese botón. En el menú, <code>opcion</code> es el botón elegido y cada caso indica qué hacer. <code>De Otro Modo</code> atiende los números que no tienen una opción prevista.</p>
</aside>

<p><strong>MINIRRETO</strong></p>

## Bucles o repeticiones

Ya conocemos los bucles: repiten un bloque de instrucciones y cada vuelta es una **iteración**. Al trasladarlos a PSeInt, debemos conservar cuándo se comprueba la condición y qué hace que termine la repetición.

| Estructura que ya conocemos | Escritura en PSeInt | Cuándo termina |
| --- | --- | --- |
| `WHILE` | `Mientras ... Hacer ... FinMientras` | Cuando la condición es falsa. |
| Comprobación al final, como en `DO-WHILE` | `Repetir ... Hasta Que` | Cuando la condición de salida es verdadera. |
| `FOR` | `Para ... Hasta ... Hacer ... FinPara` | Cuando se completa el recorrido indicado. |

<aside class="java-document-note">
<p><strong>TRES FORMAS DE ENTRENAR</strong></p>
<ul>
<li><strong>Mientras tengas energía</strong>, haces otra repetición: compruebas antes y quizá no hagas ninguna.</li>
<li><strong>Prueba un lanzamiento y repite hasta encestar</strong>: lanzas al menos una vez y compruebas después.</li>
<li><strong>Haz cinco lanzamientos</strong>: conoces de antemano el número de repeticiones y puedes usar <code>Para</code>.</li>
</ul>
<p>La pregunta para elegir es: <strong>¿compruebo antes, compruebo después o recorro una cantidad conocida?</strong></p>
</aside>

### Mientras: comprobar antes de repetir

`Mientras` comprueba la condición antes de cada vuelta y continúa si es verdadera. Puede ejecutar su cuerpo cero veces.

**Ejercicio: multiplicar mediante sumas sucesivas.** Sumaremos `a` un total de `b` veces. Para esta versión, `a` es un entero y `b` debe ser un entero mayor o igual que cero.

```text
Algoritmo MultiplicarConSumas
    Definir a, b, producto, contador Como Entero;

    Escribir "Introduce el primer entero:";
    Leer a;
    Escribir "Introduce el segundo entero (0 o mayor):";
    Leer b;

    Si b < 0 Entonces
        Escribir "El segundo numero no puede ser negativo.";
    Sino
        producto <- 0;
        contador <- 0;
        Mientras contador < b Hacer
            producto <- producto + a;
            contador <- contador + 1;
        FinMientras
        Escribir "El producto es: ", producto;
    FinSi
FinAlgoritmo
```

Para `a = 4` y `b = 3`:

| Momento | contador | producto |
| --- | --- | --- |
| Antes del bucle | 0 | 0 |
| Después de la primera vuelta | 1 | 4 |
| Después de la segunda vuelta | 2 | 8 |
| Después de la tercera vuelta | 3 | 12 |

Con `b = 0` no entra en el bucle y el producto es `0`. El incremento del contador permite llegar a una condición falsa y terminar.

### Repetir: comprobar después de ejecutar

`Repetir...Hasta Que` ejecuta el cuerpo al menos una vez y termina cuando la condición final es verdadera.

<aside class="java-document-note">
<p><strong>LA CONDICIÓN DE SALIDA</strong></p>
<p>En PSeInt, <code>Repetir...Hasta Que</code> comprueba la condición al final y termina cuando esta es verdadera. Para repetir un menú mientras la opción sea distinta de 5, escribimos <code>Hasta Que opcion = 5</code>.</p>
</aside>

**Ejercicio:** mostrar un menú de cinco opciones, repetirlo con las opciones 1 a 4 y terminar con la 5.

```text
Algoritmo MenuRepetido
    Definir opcion Como Entero;

    Repetir
        Escribir "1. Opcion 1";
        Escribir "2. Opcion 2";
        Escribir "3. Opcion 3";
        Escribir "4. Opcion 4";
        Escribir "5. Salir";
        Leer opcion;

        Segun opcion Hacer
            1, 2, 3, 4, 5:
                Escribir "Has seleccionado la opcion ", opcion;
            De Otro Modo:
                Escribir "La opcion seleccionada no es valida.";
        FinSegun
    Hasta Que opcion = 5

    Escribir "Adios!";
FinAlgoritmo
```

Prueba la secuencia `2, 8, 5`: informa de la opción 2, rechaza la 8 y, tras anunciar la opción 5, muestra `Adios!` y termina.

### Para: repetir un número conocido de veces

`Para` utiliza una variable de control, un valor inicial, un valor final y un paso. Si no indicamos el paso, es 1. El valor final está incluido si el recorrido llega a él.

```text
Algoritmo MostrarIndices
    Definir indice Como Entero;

    Para indice <- 0 Hasta 10 Con Paso 1 Hacer
        Escribir "El valor del indice es: ", indice;
    FinPara
FinAlgoritmo
```

Muestra del `0` al `10`: son **11 iteraciones**. Para contar hacia atrás, podemos usar `Para indice <- 10 Hasta 0 Con Paso -1 Hacer`.

**Ejercicio: pedir cinco números y sumar sus valores.**

```text
Algoritmo SumarCincoNumeros
    Definir indice Como Entero;
    Definir numero, suma Como Real;

    suma <- 0;
    Para indice <- 1 Hasta 5 Hacer
        Escribir "Introduce el numero ", indice, ":";
        Leer numero;
        suma <- suma + numero;
    FinPara
    Escribir "La suma es: ", suma;
FinAlgoritmo
```

Con `2, 4, 6, 8, 10`, el resultado es `30`.

## Contadores, acumuladores y banderas

Ahora combinaremos las **variables**, las **asignaciones** y los **bucles** que ya hemos estudiado. Una variable puede contar sucesos, acumular cantidades o recordar si se ha cumplido una condición. Son distintos usos de las variables; no son tipos de datos nuevos.

### Contador: cuántas veces ocurre algo

Un contador empieza normalmente en cero y aumenta en uno cuando sucede lo que queremos contar.

**Ejercicio:** leer diez números y contar cuántas veces aparece el 5.

```text
Algoritmo ContarCincos
    Definir indice, numero, cantidadCincos Como Entero;

    cantidadCincos <- 0;
    Para indice <- 1 Hasta 10 Hacer
        Escribir "Introduce el entero ", indice, ":";
        Leer numero;
        Si numero = 5 Entonces
            cantidadCincos <- cantidadCincos + 1;
        FinSi
    FinPara
    Escribir "Has introducido un 5 estas veces: ", cantidadCincos;
FinAlgoritmo
```

Con `5, 2, 5, 7, 8, 5, 1, 0, 5, 3`, muestra `4`. La variable `indice` cuenta las lecturas y `cantidadCincos` cuenta solo las coincidencias.

### Acumulador: cuánto llevamos en total

Un acumulador suma cantidades que pueden ser distintas. En `SumarCincoNumeros`, la variable `suma` es el acumulador y se actualiza con `suma <- suma + numero;`.

| Número leído | Valor de suma después de acumular |
| --- | --- |
| 2 | 2 |
| 4 | 6 |
| 6 | 12 |
| 8 | 20 |
| 10 | 30 |

<aside class="java-document-note">
<p><strong>INICIALIZAR UNA SOLA VEZ</strong></p>
<p>En una suma acumulada, escribe <code>suma &lt;- 0;</code> antes del bucle. Si la colocas dentro, borrarás lo acumulado en cada vuelta. Un contador suma normalmente 1; este acumulador suma el valor leído.</p>
</aside>

### Bandera o flag: recordar si ha ocurrido algo

Una bandera es una variable lógica que representa un estado. Puede servir para recordar un suceso o para indicar que debemos finalizar.

**Ejercicio:** pedir números hasta introducir un 0. Usaremos `terminado` para controlar la salida y otra bandera para recordar si apareció algún negativo.

```text
Algoritmo LeerHastaCero
    Definir numero Como Real;
    Definir terminado, hayNegativos Como Logico;

    terminado <- Falso;
    hayNegativos <- Falso;
    Mientras NO terminado Hacer
        Escribir "Introduce un numero (0 para terminar):";
        Leer numero;
        Si numero = 0 Entonces
            terminado <- Verdadero;
        Sino
            Si numero < 0 Entonces
                hayNegativos <- Verdadero;
            FinSi
        FinSi
    FinMientras

    Si hayNegativos Entonces
        Escribir "Has introducido algun numero negativo.";
    Sino
        Escribir "No has introducido numeros negativos.";
    FinSi
FinAlgoritmo
```

Con `4, -2, 7, 0`, la bandera `hayNegativos` pasa a verdadera al leer `-2` y conserva ese valor. Si el primer dato es `0`, el programa termina sin registrar negativos. El `0` actúa como **centinela**: un valor especial que indica el final de la entrada.

## Arrays o arreglos: guardar varios datos

Un **array**, también llamado **arreglo** o **vector** cuando tiene una dimensión, guarda varios valores del mismo tipo bajo un único nombre. En lugar de declarar `nota1`, `nota2` y `nota3`, podemos utilizar `notas` y acceder a cada elemento mediante su **índice**, escrito entre corchetes.

### Declarar, dimensionar y acceder a un elemento

`Definir` indica el tipo de los elementos y `Dimension` reserva el número de posiciones:

```text
Definir notas Como Real;
Dimension notas[3];

notas[0] <- 6;
notas[1] <- 8;
notas[2] <- 7;
Escribir notas[1];
```

| Índice | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Valor guardado | 6 | 8 | 7 |

`notas[1]` muestra `8`: el índice identifica la posición, no el valor. Podemos modificar solo esa posición con `notas[1] <- 9;` sin cambiar las demás.

<aside class="java-document-note">
<p><strong>EL PRIMER ÍNDICE DEPENDE DEL PERFIL</strong></p>
<p>Estos ejemplos utilizan <strong>base 0</strong>: un array de 3 elementos tiene índices de 0 a 2. PSeInt también permite perfiles con <strong>base 1</strong>, donde los índices serían de 1 a 3. Revisa las opciones del lenguaje en el menú <strong>Configurar</strong>. Con base 0, <code>notas[3]</code> queda fuera del array; dimensionar 3 posiciones no crea una cuarta.</p>
</aside>

### Recorrer un array con un bucle

Un bucle `Para` permite leer o procesar todos los elementos cambiando el índice en cada vuelta. **Ejemplo:** guardar cinco notas y calcular su media.

```text
Algoritmo MediaDeNotas
    Definir notas, suma, media Como Real;
    Definir i Como Entero;
    Dimension notas[5];

    suma <- 0;
    Para i <- 0 Hasta 4 Hacer
        Escribir "Introduce la nota ", i + 1, ":";
        Leer notas[i];
        suma <- suma + notas[i];
    FinPara
    media <- suma / 5;

    Para i <- 0 Hasta 4 Hacer
        Escribir "Nota ", i + 1, ": ", notas[i];
    FinPara
    Escribir "La media es: ", media;
FinAlgoritmo
```

Con las notas `6, 8, 7, 9, 5`, la suma es `35` y la media es `7`. Mostramos `i + 1` para numerar las notas del 1 al 5, aunque sus índices van del 0 al 4. Guardar las notas permite volver a consultarlas después del primer bucle. Asigna o lee cada elemento antes de utilizarlo en un cálculo.

Si utilizas base 1, cambia **los dos recorridos** a `Para i <- 1 Hasta 5 Hacer` y muestra `i` en los mensajes. La dimensión sigue siendo `5`.

### Arrays de dos dimensiones: matrices

Una **matriz** organiza los datos en filas y columnas. `Dimension tablero[2, 3];` reserva 2 filas y 3 columnas: 6 elementos. En base 0, las filas van de 0 a 1 y las columnas de 0 a 2.

```text
Definir tablero Como Entero;
Dimension tablero[2, 3];
tablero[0, 2] <- 9;
Escribir tablero[0, 2];
```

El primer índice indica la fila y el segundo la columna. Para recorrer toda una matriz podemos utilizar dos bucles anidados: uno para las filas y otro para las columnas.

**Tu turno:** guarda cinco números en un array y, en un segundo recorrido, muestra cuántos son mayores que su media. Prueba también con cinco números iguales: el contador debe ser `0`.

## Funciones y subprocesos

En **Algoritmos y programas** hablamos de descomponer un problema en otros más pequeños. En PSeInt podemos aplicar esa idea agrupando las instrucciones de cada tarea en un subprograma y utilizándolo mediante una llamada. Puede recibir datos, llamados **parámetros**, y puede devolver un resultado.

Para definir estos bloques escribimos `Funcion` y `FinFuncion`. PSeInt también admite `SubProceso` y `FinSubProceso`, como en los [ejemplos oficiales](https://pseint.sourceforge.net/index.php?cual=Subprocesos&mode=estricto&page=ejemplos.php). Distinguiremos los que realizan una acción de los que devuelven un valor.

<aside class="java-document-note">
<p><strong>ENCARGAR UNA TAREA</strong></p>
<p>Llamar a un subproceso se parece a encargar una tarea a un compañero. Le dices cuál es la tarea y le entregas los datos que necesita: los <strong>parámetros</strong>. <code>Saludar("Ana")</code> le pide que muestre un saludo. <code>CalcularAreaTriangulo(5, 8)</code> le entrega dos medidas y espera un número de vuelta. <strong>Hacer algo y devolver un resultado son cosas distintas.</strong></p>
</aside>

### Subproceso sin valor de retorno

**Ejemplo:** saludar a una persona. El subproceso recibe el nombre y muestra el saludo.

```text
Funcion Saludar(nombre)
    Escribir "Hola, ", nombre, "!";
FinFuncion

Algoritmo Saludos
    Saludar("Ana");
    Saludar("Pau");
FinAlgoritmo
```

Muestra `Hola, Ana!` y `Hola, Pau!`. `nombre` es el parámetro; `"Ana"` y `"Pau"` son los datos que entregamos en cada llamada. Mostrar texto en pantalla no equivale a devolver un valor al programa que llama.

### Función con valor de retorno

**Ejemplo:** calcular el área de un triángulo y guardar el resultado en el programa principal.

```text
Funcion area <- CalcularAreaTriangulo(base, altura)
    Definir area Como Real;
    area <- (base * altura) / 2;
FinFuncion

Algoritmo UsarAreaTriangulo
    Definir resultado Como Real;

    resultado <- CalcularAreaTriangulo(5, 8);
    Escribir "El area del triangulo es: ", resultado;
FinAlgoritmo
```

1. El programa llama a `CalcularAreaTriangulo` con `5` y `8`.
2. Dentro del subproceso, `base` vale `5` y `altura` vale `8`.
3. Se calcula `20` y se asigna a `area`, la variable de retorno indicada en la cabecera.
4. El valor devuelto se guarda en `resultado` y el programa principal lo muestra.

La variable `area` pertenece al subproceso y `resultado` al programa principal. No necesitan tener el mismo nombre.

## Funciones e instrucciones útiles de PSeInt

PSeInt incorpora funciones que podemos llamar sin definirlas nosotros. **Una función devuelve un valor**, como `Azar(6)`; **una instrucción realiza una acción**, como `Limpiar Pantalla`. Por eso guardamos el resultado de la primera con una asignación, mientras escribimos la segunda directamente.

### Generar un número aleatorio

`Azar(n)` devuelve un entero entre `0` y `n - 1`, ambos incluidos; `n` debe ser un entero positivo. Para simular un dado usamos `Azar(6) + 1`: primero obtenemos un número de 0 a 5 y después sumamos 1.

```text
Algoritmo LanzarDado
    Definir dado Como Entero;
    dado <- Azar(6) + 1;
    Escribir "Has sacado: ", dado;
FinAlgoritmo
```

También puedes utilizar `Aleatorio(1, 6)`, que incluye los dos extremos. Para un intervalo de enteros con `minimo <= maximo`, la fórmula equivalente es `Azar(maximo - minimo + 1) + minimo`. Por ejemplo, `Azar(11) + 10` genera valores del 10 al 20. El resultado puede repetirse: aleatorio no significa distinto en cada llamada.

### Pasar un texto a mayúsculas o minúsculas

| Función | Ejemplo | Resultado |
| --- | --- | --- |
| `Mayusculas(texto)` | `Mayusculas("Hola")` | `"HOLA"` |
| `Minusculas(texto)` | `Minusculas("Hola")` | `"hola"` |

Estas funciones devuelven el texto convertido. Para modificar la variable original, asigna el resultado: `nombre <- Mayusculas(nombre);`.

```text
Algoritmo ComprobarRespuesta
    Definir respuesta Como Caracter;
    Escribir "Quieres continuar? (SI/NO)";
    Leer respuesta;
    respuesta <- Minusculas(respuesta);
    Si respuesta = "si" Entonces
        Escribir "Continuamos!";
    Sino
        Escribir "No has respondido si.";
    FinSi
FinAlgoritmo
```

Así aceptamos `SI`, `Si` o `si` con una sola comparación. La conversión no elimina espacios ni tildes: `" sí "` sigue siendo diferente de `"si"`. Si el perfil rechaza las funciones de cadenas, habilítalas en las opciones del lenguaje del menú **Configurar**, como indica el [ejemplo oficial de cadenas](https://pseint.sourceforge.net/index.php?cual=Cadenas&mode=estricto&page=ejemplos.php).

### Limpiar la pantalla y hacer pausas

| Instrucción | Para qué sirve |
| --- | --- |
| `Limpiar Pantalla;` | Borra el texto mostrado; también se puede escribir `Borrar Pantalla;`. |
| `Esperar 2 Segundos;` | Detiene la ejecución durante dos segundos y después continúa. |
| `Esperar 500 Milisegundos;` | Espera medio segundo: 1000 milisegundos equivalen a un segundo. |
| `Esperar Tecla;` | Espera hasta que el usuario pulse una tecla. |

Limpiar la pantalla no borra las variables. `Esperar Tecla` permite que el usuario lea un mensaje antes de borrarlo; una espera de segundos continúa automáticamente.

```text
Algoritmo CuentaAtras
    Definir i Como Entero;
    Escribir "Pulsa una tecla para empezar.";
    Esperar Tecla;
    Para i <- 3 Hasta 1 Con Paso -1 Hacer
        Limpiar Pantalla;
        Escribir i;
        Esperar 1 Segundos;
    FinPara
    Limpiar Pantalla;
    Escribir "Adelante!";
FinAlgoritmo
```

La pantalla muestra `3`, `2` y `1`, dejando un segundo entre ellos, y finalmente `Adelante!`. El [ejemplo oficial Misil](https://pseint.sourceforge.net/index.php?cual=Misil&mode=estricto&page=ejemplos.php) combina estas instrucciones para crear una animación.

**Tu turno:** pide el nombre del jugador, muéstralo en mayúsculas, espera una tecla y limpia la pantalla. Después lanza un dado, espera dos segundos y muestra el resultado.

## Cómo comprobar tus algoritmos

Antes de ejecutar, escribe qué resultado esperas. Después utiliza la ejecución paso a paso para observar las variables y las decisiones.

| Qué comprobar | Prueba concreta |
| --- | --- |
| Un caso habitual | Área con base 5 y altura 8: 20. |
| El límite de una condición | En el saludo, probar 3 y 4. |
| Todas las alternativas | Menú con 1, 2, 3 y una opción no válida. |
| Un bucle que no entra | Multiplicación con segundo factor 0. |
| La salida en la primera vuelta | Menú repetido con 5 como primera opción. |
| Ausencia de coincidencias | Diez números sin ningún 5: contador 0. |
| El valor que detiene la lectura | Introducir 0 como primer dato en `LeerHastaCero`. |

Si el resultado no coincide, localiza la primera instrucción donde el valor obtenido difiere del que habías calculado en papel.
