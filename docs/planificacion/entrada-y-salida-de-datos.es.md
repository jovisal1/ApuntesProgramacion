# Reorganización de entrada y salida de datos

Plan confirmado por el profesor el 31 de octubre de 2026.

Crear un grupo desplegable con siete páginas: introducción; salida por consola; entrada con Scanner; tokens, líneas y decimales; validación de entradas; ejemplos completos; ventanas con JOptionPane como ampliación. Conservar la dirección original para la introducción y la navegación propia de Starlight.

Eliminar «Practica con soluciones», sus cuatro ejercicios y soluciones. Conservar los restantes ejemplos y programas completos: la media de notas y el menú se mantienen en Ejemplos completos. Repartir las tablas existentes de repaso y errores entre las páginas correspondientes. Mantener las versiones castellana y valenciana, los enlaces y las referencias.

Es una reorganización del contenido existente; no se generan nuevas diapositivas. Las ventanas requieren un escritorio gráfico para ejecutarse: si el entorno no permite probarlas, compilar el ejemplo y señalar la limitación. La versión docente de Java sigue pendiente; Java 21 se usa solo para las comprobaciones.
