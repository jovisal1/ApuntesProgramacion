# Testing amb JUnit

El professor sol·licita que Testing siga una unitat independent com Funcions en Java. Es conserva el contingut confirmat i es repartix en huit pàgines, amb grup propi al mateix nivell del sidebar: introducció; preparar projecte; primera prova; executar proves; casos de prova; assercions; cicle de vida; errors i correccions. Rutes guides/testing-con-junit i les seues subpàgines; traduccions equivalents en ca/guides/.

Es conserven tots els blocs de codi en dividir el material. S’ajusten els contextos, enllaços entre pàgines, recursos de la introducció, enllaços des de Funcions i README dels exemples. Els exemples Java ja verificats es mantenen sense canvis. Els README del projecte reflectixen les quatre unitats. Les decisions prèvies i les seues verificacions es conserven en funciones-java.ca.md.

El professor retira el bloc Projecte descarregable, les seues referències en els apunts i les explicacions sobre Astro/npm/package.json. Els exemples es construïxen pas a pas; el total de tests depén dels que s’hagen incorporat. El test inicial compta com un; la classe de cicle de vida n’aporta dos. Els fonts de verificació i els seus artefactes es conserven, sense promocionar la descàrrega en els apunts.

Les diapositives també se separen: Funcions en conserva 15 i Testing en té 12 en ../Diapositivas/testing-con-junit-{es,ca}.html, amb entrada pròpia en l’índex. No s’enllacen des dels apunts.

Validació: Astro compila 85 pàgines; 1056 enllaços i recursos comprovats en les 16 pàgines de Testing sense incidències. Els fonts Java són idèntics als que ja superaren els 18 tests per idioma. Presentacions separades amb 15 i 12 diapositives per idioma, recursos locals vàlids i ZIP sincronitzats després d’actualitzar els seus README. La revisió visual en navegador continua pendent.
