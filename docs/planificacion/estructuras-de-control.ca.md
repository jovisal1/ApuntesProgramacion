# Reorganització d’estructures de control

Pla confirmat pel professor el 31 d’octubre de 2026.

Crear un grup desplegable amb introducció general i tres subseccions: estructures de selecció, d’iteració i de salt. La introducció conserva la ruta original. Cada pàgina comença directament amb l’explicació, sense blocs inicials de recorregut ni navegació manual al final.

Conservar els exemples i les activitats. Traslladar FizzBuzz a iteració, perquè combina condicions i bucles. Repartir repàs i errors freqüents entre les pàgines corresponents. Adaptar les rutes dels diagrames al nou nivell de carpeta i mantindre els idiomes castellà i valencià. No introduir mètodes propis: l’exemple existent de return es conserva dins de main.

Es tracta d’una reorganització del contingut existent, amb una introducció contextualitzada; no s’amplia el temari ni es generen diapositives noves. Les convencions reutilitzables es mantenen en ../Skills/editar-apuntes-java/SKILL.md.
